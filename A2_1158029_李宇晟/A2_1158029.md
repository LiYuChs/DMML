# A2_1158029_報告

## 1. 研究問題與作業背景
### 1.1 研究問題
本研究探討分層抽樣（Stratified Sampling）對分類模型在處理醫療不平衡資料（MIMIC3C）時，其 macro F1 表現的影響。實驗設計涵蓋了三種資料量（n=100, 500, 6000）與 7 種不同類型的機器學習模型。

### 1.2 為何要在 MIMIC3C 醫療資料上重做這個實驗的動機
W7_20260416 報告指出任務難度與資料量會影響分層抽樣的效益，但該研究主要基於合成與影像資料。醫療臨床資料具有高度雜訊且特徵間關係複雜，透過在 MIMIC3C 上複現該實驗，並延伸加入隨機森林（Random Forest）與單純貝氏（Naïve Bayes），能驗證原報告發現於臨床預後預測情境下的適用性。

## 2. 實驗設定與標籤洩漏檢查
### 2.1 MIMIC3C 描述
* **來源**：Kaggle MIMIC-III C Clinical Database。
* **Target**：`ExpiredHospital`（0=存活出院，1=院內死亡）。
* **難度定位**：根據實驗結果，模型之平均 macro F1 最高約為 0.688（RandomForest），顯著低於 MNIST 的表現，故定位為「困難（Hard）」任務。
* **採用方案**：方案 A（重用 HW1 之 `df_model_ready.csv`）。
* **最終納入特徵欄位數**：29。
* **y=1 比例**：強制抽樣為 9:1。

### 2.2 標籤洩漏檢查清單
'ExpiredHospital' --> 預測目標
'LOSdays' --> 出院存活與否才能計算總住院天數。
'LOSgroupNum' --> 同上，基於住院天數進行分組。
'AdmitDiagnosis' --> 診斷評估
'AdmitProcedure' --> 入院處置

### 2.3 模型清單
* 既有模型：DecisionTree, KNN, LogisticReg, SVM (RBF), MLP (3層)。
* 新加模型：Random Forest, Naïve Bayes。

### 2.4 實驗參數
* **不平衡比例**：9:1。
* **Size Grid**：n=[100, 500, 6000]。
* **Seed 數**：20 (0..19)。
* **評估指標**：macro F1。

## 3. 結果：複現 W7_20260416 的五段分析
### 3.1 Paired t-test 顯著結果總覽
在 21 組（3 size × 7 model）實驗組合中，`significance_full.csv` 顯示沒有任何一組達到 p < 0.05 的顯著水準（`significance_table.md` 目前僅有表頭）。這表示在 MIMIC3C 資料上，分層抽樣與隨機抽樣在 macro F1 表現上無統計上的顯著差異。

### 3.2 顯著結果隨 n 分布
由於所有 p 值均 > 0.05，顯著結果隨 n 分布呈現「零顯著」狀態。最接近顯著門檻者出現在 n=100（例如 SVM: p=0.0583、KNN: p=0.0583、MLP: p=0.0996），但皆未達統計顯著。

### 3.3 最大資料量下的差異均值方向
在 n=6000 時，各模型的 mean_diff 皆非常接近 0（約 -0.0139 到 +0.0008）。其中僅 RandomForest 為微幅正值（+0.00084），其餘模型為微幅負值（例如 DecisionTree: -0.00082），且皆不具顯著性。

### 3.4 Ceiling effect 跨模型比較
分析 n=500 之數據：
* 所有模型之平均 F1 均未超過 0.95（最高為 RandomForest 0.689）。
* diff_std 最小者為 MLP (0.0073)，其次為 SVM (0.0189) 與 NaiveBayes (0.0530)，顯示部分模型對抽樣策略差異相對不敏感，且非因分數達到天花板所致。

### 3.5 小資料下的 F1 std ratio
於 n=100 時，7 個模型的 std ratio 皆小於 1.0：
* DecisionTree: 0.886
* KNN: 7.77e-16
* LogisticReg: 0.774
* SVM: 7.77e-16
* MLP: 0.341
* RandomForest: 0.795
* NaiveBayes: 0.665
這顯示分層抽樣在極小樣本（n=100）下，整體上能降低 macro F1 的變異（Variance）。

## 4. 三大發現的檢驗
### 4.1 發現一：任務難度決定 Stratified 是否重要——不成立
W7 認為困難任務上 Stratified 應一致性正向。但在 MIMIC3C 這一困難任務中，並無任何組合達到顯著。這說明在具備高度真實世界雜訊的醫療資料中，Stratified 的重要性被資料本身的變異性（Intrinsic Noise）所稀釋。

### 4.2 發現二：Stratified 在小資料上降低變異——成立
數據支持此點。在 n=100 時，7 個模型的 ratio 全部 < 1.0（7.77e-16 到 0.886），代表分層抽樣穩定了測試集的分佈，進而降低評估指標的波動。

### 4.3 發現三：Ceiling effect 解釋 MLP 表面穩定性——不成立（挑戰原發現）
W7 認為 MLP 的穩定是高分導致的假象。但在本實驗 n=500 中，MLP 之平均 F1 約 0.472，遠低於 ceiling 門檻；同時其 diff_std 約 0.0073，為全模型最小。這強烈支持「MLP 的穩定性不來自高分天花板，而是其架構特性」的判斷。

## 5. 與 W7_20260416 既有結果的對照討論
### 5.1 新模型行為
RandomForest 在 n=500 的平均 F1 為全模型最高（0.689），顯示其在此資料上的整體效能優勢。就 n=100 的變異比來看，DecisionTree (ratio=0.886) 與 RandomForest (ratio=0.795) 皆小於 1.0，代表分層抽樣對兩者都有穩定化效果。MLP 在 n=100 的 ratio 最低（0.341），顯示最優穩定性。NaiveBayes 在本資料集整體表現較差（mean F1 約 0.243）。

### 5.2 醫療資料特性
對比原報告之 MNIST/CIFAR-10，MIMIC3C 的結果顯示「三大發現」在醫療情境下有所偏移。這說明任務「難度」並非影響抽樣策略效益的唯一變因，「雜訊強度」與「特徵品質」可能更具關鍵性。

## 6. 實驗限制
1. **單一資料集**：結論僅限於 MIMIC3C。
2. **固定比例**：僅測試 9:1 比例，未探討極端不平衡下 Stratified 的必要性。
3. **重複次數**：20 seeds 在高雜訊資料下可能仍有抽樣誤差。
